# Commissioner FAQ - Pick the Game Pools

### What powers does a commissioner have?
**Tags:** permissions, admin, management

Commissioners have full control over their pool. They can:

- Add players
- Modify gameplay settings
- Choose which games count for a week
- Configure standings columns
- View pick submission status
- Submit picks on behalf of players
- Edit player picks
- Send pool-wide updates
- Remove players

### Can a commissioner edit someone else's picks?
**Tags:** edit picks, permissions, notifications

Yes. Commissioners can edit a player's picks.

The player will receive an email notification when changes are made.

### Can a commissioner lock or remove a player?
**Tags:** remove player, management, permissions

Yes. Commissioners can remove a player at any time during the season.

### Can commissioner duties be transferred?
**Tags:** transfer, roles, admin

Yes. A commissioner can promote any player to commissioner status.

Multiple commissioners are allowed per pool.

### Can commissioners customize pool rules mid-season?
**Tags:** rules, settings, midseason

Yes. Commissioners can modify many pool rules during the season, including game type, submission schedule, survivor settings, and standings columns.

Weekly game selection can be changed only while that week's edit window is open. Once the weekly edit window closes, selected games are locked.

### Can commissioners choose which games count for the current week?
**Tags:** game-selection, settings, weekly

Yes. Go to:

**Pool Settings -> Week Settings -> Game Selection**

Commissioners can select all games, clear the week, search by team, and choose the exact games that count for the current week.

### Can commissioners control standings columns?
**Tags:** standings, settings, columns, tiebreaker

Yes. Go to:

**Pool Settings -> Standings Columns**

Commissioners can show or hide total correct picks, lowest week, adjusted totals, confidence point totals, lowest confidence point week, and cumulative tiebreaker margin. Confidence point columns only appear for Confidence pools.
