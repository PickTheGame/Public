# General FAQ - Pick the Game Pools

### Do you offer playoff pools?
**Tags:** playoff, postseason, pools, formats

Yes. In addition to regular-season pools, we offer postseason formats including playoff Pick'em and Super Bowl Squares. You can create or join them from your dashboard when postseason contests are open.

### Will playoff picks count toward season standings?
**Tags:** playoff, standings, season, scoring

Yes. If your pool is configured for season-long standings, playoff results will continue to accumulate into the year-to-date totals for all players.

### Can I see weekly standings throughout the season?
**Tags:** standings, weekly, results, rankings

Yes. Pool commissioners and members can view both:

- Weekly results
- Cumulative season standings

This allows you to track performance week-by-week as well as overall rankings.

### What types of pools do you offer?
**Tags:** pools, formats, confidence, survivor, squares

We offer multiple pool formats to fit any group:

- **Pick'Em** - Pick the winner of each game.
- **Confidence** - Pick winners and rank them for weighted points.
- **Survivor** - Choose one winning team each week. Pools can allow multiple survivor entries.
- **Squares** - A grid-based format, ideal for championship games.

### What's the difference between Confidence and Pick'Em pools?
**Tags:** confidence, pickem, scoring, formats

In **Confidence Pools**, you pick winners and rank them. Higher-ranked picks earn more points if correct.

In **Pick'Em**, you simply select the winner of each game. All correct picks are worth the same value.

### Can I customize scoring rules?
**Tags:** scoring, customization, rules

Yes. Commissioners can manage common options in pool and game settings, including game type, weekly game selection, submission schedule, survivor entry rules, and standings columns.

If your pool needs a rule that is not available in settings, contact support.

### Can I create a private pool?
**Tags:** private, invite, access

Yes. All pools are private.

You control access by sharing your custom invite link with the people you want to join.

### Is there a limit to how many people can join a pool?
**Tags:** limits, pool size, members

No. We support pools of all sizes - from small groups to large organizations.

### Can one person join multiple pools?
**Tags:** multiple pools, account, access

Yes. One login can participate in multiple pools.

Switch between them anytime using the pool dropdown in the main menu.

### Can I duplicate a pool from last season?
**Tags:** returning users, seasons, renewal

There's no need to duplicate your pool.

Simply log in each season and continue running your existing pool.

### Can I edit pool settings after the season starts?
**Tags:** settings, commissioner, edits

Yes. Commissioners can update pool settings during the season.

Some weekly settings, such as which games count for the current week, lock once the weekly edit window closes.

### What if the commissioner forgets to set up the pool before Week 1?
**Tags:** late start, setup, midseason

No problem. You can start a pool at any time during the season and begin play in any week.

### What is Coach AI?
**Tags:** coach-ai, help, assistant, pool

Coach AI is an in-app pool assistant. You can ask questions about your pool, such as who still needs to make picks, current standings, pick history, square results, survivor status, or where to find a setting.

Coach AI answers using current pool data and may include tables or navigation shortcuts when helpful.
