# Pool Settings FAQ - Pick the Game Pools

### My pool switched to Confidence picks - can I change it back to Pick'em?
**Tags:** pool-settings, confidence, pickem, configuration

Pool type is set in pool settings. Commissioners can use **Game Type** to switch between Pick'em and Confidence for upcoming weeks when available.

If the option is locked for your pool, contact support and it can be adjusted for you.

### Can submission schedules be changed during the season?
**Tags:** submission, schedule, pool-settings, deadlines

Yes. Commissioners can modify submission timing anytime:

**Pool Settings -> Submission Schedule**

Options include:

- Before all games
- Before Sunday games
- Before each game

### Can I choose which games count for a week?
**Tags:** game-selection, weekly, settings

Yes. Commissioners can use **Game Selection** to select the games that count for the current week.

The page includes search, select all, and clear all controls. Game selection can be edited only while the weekly edit window is open.

### Can I allow multiple Survivor entries?
**Tags:** survivor, entries, settings

Yes. Commissioners can open **Survivor Settings** and set how many extra Survivor entries players may add before their first Survivor submission.

Each entry is tracked as a separate Survivor series.

### Can I customize what appears on standings?
**Tags:** standings, columns, settings

Yes. Commissioners can open **Standings Columns** and show or hide optional standings stats, including season totals, lowest week, adjusted totals, confidence point totals, and tiebreaker margin.
